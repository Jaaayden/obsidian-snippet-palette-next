# Implementation provenance

The user's feature requirements began with experience using [Ribbon Snippets](https://github.com/mriechers/obsidian-ribbon-snippets). An earlier derived project exists separately at [Snippet Palette](https://github.com/Jaaayden/obsidian-snippet-palette).

For this repository, the user explicitly requested a new repository and a complete reimplementation. This repository was initialized with a new Git history. Its application source, styles, tests, documentation, and workflows were newly authored from the requested behavior; files and commits from the earlier implementation were not imported. Obsidian's public SDK and standard development libraries are used as dependencies.

The assistant that authored this implementation had previously seen the earlier implementation in the same conversation. This is therefore **not a clean-room claim**, and creating a new repository or rewriting code does not itself establish that the Obsidian community directory will classify the project as independent. The directory's maintainers make that decision under their current policies. No original-author approval or community-directory acceptance is claimed.

Any local conversion of a user's saved snippets transfers that user's configuration, not source code from the earlier project. Private snippets and vault data are excluded from this repository and release artifacts.
