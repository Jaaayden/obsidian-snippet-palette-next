First release of the new Snippet Palette Next implementation.

Includes a dockable colored palette, optional searchable icons, hidden-by-default search, compact settings, drag and keyboard sorting, explicit Save/Cancel editing, Chinese/English localization, and three insertion positions.

New plugin ID: `snippet-palette-next`. Previous plugin data requires explicit migration and backup. This release is not an announcement of community-directory acceptance. See PROVENANCE.md for implementation history and limitations.
